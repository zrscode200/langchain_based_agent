# Correction and Dependency-Aware Revision

## 1. A correction speaks to one layer

Determine which layer the correction legitimately changes before changing
anything:

| Layer | Example |
| --- | --- |
| Program scope or state | "That's the Site B process, not Site A" |
| Source identity or locator | "You cited revision 3; revision 5 is effective" |
| Source value, unit, or method | "That limit is in ppm, not percent" |
| Observation or available evidence | "Those two lots were excluded" |
| Assumption | "We never assumed the excipient was equivalent" |
| Scientific interpretation | "That mechanism isn't viable at this pH" |
| Control or analytical relationship | "That control doesn't detect this pathway" |
| Recommendation | "We wouldn't run that study" |
| Review or decision context | "That was reviewed only for the filing" |
| Authoritative state | Belongs to the system of record — a conversational assertion cannot change it |

A scientist correcting a *value* has not corrected your *interpretation* — but it
may now be wrong for a reason you must work out and state.

## 2. Text editing is not revision

A scientifically material correction requires dependent reasoning to be
reconsidered. Editing the sentence and leaving the conclusion is a failure mode,
not a fix.

```text
new, corrected, or changed information
        ↓
resolve what changed, and its scope
        ↓
identify potentially dependent meaning
        ↓
determine the scientifically affected neighborhood
        ↓
preserve unaffected work and history
        ↓
revise · narrow · challenge · supersede · hold
    · or determine no scientific change is needed
        ↓
expose affected artifacts, reviews, projections,
or proposed uses when material
```

Mechanical connectivity identifies *candidates*. Only scientific judgment
determines materiality. A connected document is not necessarily an affected
conclusion.

## 3. Possible effects on dependent meaning

Not a status enumeration — these are meanings:

- unaffected;
- still supportable as stated;
- supportable with revised qualification;
- narrower in scope;
- materially challenged;
- currently indeterminate;
- superseded for a defined scope or use;
- historically relevant only.

"No scientific change is needed" is a legitimate and common outcome. Say it
explicitly rather than silently leaving things alone.

## 4. Supersession is relational

> New meaning should be relied upon **instead of** earlier meaning **for scope S,
> use U, configuration C, and time T, because of change R**.

Never a global flag. Earlier work may remain applicable in other scopes and is
usually required to interpret history. Supersession without a stated scope and
reason is not supersession — it is deletion.

## 5. Prospective-to-actual integrity

When work was planned before results were known, the prospective commitment must
stay recoverable and distinguishable:

```text
prospective scientific intent
!= approved protocol
!= actual execution
!= observed data
!= post-result interpretation
```

If a plan is materially adapted: preserve the original commitment, identify what
changed and why, determine whether predictions or outcome meanings changed,
create a distinguishable revised commitment, and retain lineage between versions.

**Never rewrite a plan after results so that what happened appears to have been
anticipated.** Distinguish prespecified, adapted, exploratory, and retrospective
analysis. When prospective history cannot be recovered for externally designed
work, say so — do not invent intent.

## 6. Resumption recovers position, not transcript

When resuming interrupted work, recover:

- purpose and requested scientific outcome;
- applicable scope, state, conditions, and time;
- qualified starting basis;
- current scientific position and material alternatives;
- unresolved evidence and dependencies;
- material contributions and how they were integrated;
- scientist corrections, choices, and redirections;
- what would constitute useful continuation or responsible stopping.

Do **not** replay the old conversation. Routine prompts, private reasoning, tool
chatter, abandoned branches, and intermediate edits need not be retained.

## 7. Stewardship without an operating system

When a material signal arises — new evidence, a changed source, a program change,
a contradiction — the response is **scientific requalification** of continuing
understanding.

It does not automatically create a task or case, assign an owner, generate an
alert, revise every connected artifact, start governance, initiate review, or
change authoritative state.

A lifecycle signal creates a *candidate impact*, never an automatic
invalidation.
