# Brainstorm conversation evaluations

These are synthetic scientific scenarios. All programs, observations and papers
are invented evaluation inputs; none should be searched as real identifiers or
saved into a real program workspace. No live network or internal evidence is
needed. A packet is not an executed model result.

Give the evaluated companion the candidate root AGENTS.md, the normal skill
catalogue (names/descriptions), shared references as needed, and one initial input.
For B1/B2, explicitly invoke brainstorm with its complete SKILL.md. For B4, supply
the catalogue and ordinary input; observe selection without preloading brainstorm.
Keep this setup, the follow-up instructions and reviewer rubric out of its context.
Record the exact source revision or candidate hashes, model/runtime, available
tools, inputs actually supplied, requests, replies and limitations.

| Case | Input | What it exercises |
| --- | --- | --- |
| B1 | [Exploration](b1-exploration.md) | Develop an alternative framing, respond to a correction, then follow a request for supported interpretation. |
| B2 | [Public perspectives](b2-public-perspectives.md) | Selective use of relationships and deeper reading; develop an analogy while recognizing applicability limits. |
| B3 | [Saved conjecture](b3-reuse.md) | Recover useful speculative understanding without treating the earlier agent or a scientist's assertion as proof. |
| B4 | [Ordinary question](b4-ordinary.md) | An ordinary bounded question stays proportional with brainstorm present in the catalogue. |

After B1's first response, supply its follow-ups from [the evaluator turns](evaluator-turns.md)
one at a time. For B2, reveal only the simulated response that the companion
requests from that file. A prompt-only exercise can request a source action in
plain text; the evaluator supplies the fixture and records it as simulated access,
never as an MCP call. Do not let the evaluated model read future turns or rubrics.

An optional paired run presents B1's initial scientific material as an ordinary
request for interpretation in a fresh context. The ordinary skill may also find
alternatives; brainstorming should give worthwhile possibilities substantive
development, rather than win by being longer or less accurate.

Use the [separate rubric](reviewer-rubric.md). Model exercises assess observed
reasoning under these premises. Actual host discovery/invocation and end-to-end
tool/persistence behavior require separately identified checks; neither prompt
exercises nor loader checks establish production scientific performance.
