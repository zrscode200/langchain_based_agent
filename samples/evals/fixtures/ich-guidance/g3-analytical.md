# G3 input — synthetic program Birch

Scientist request: Our reported drug-product aggregate percentage rose after a
process change. Is that evidence the process worsened? What is the most informative
next scientific move, given the records we already have?

Coordinate: invented recombinant-protein drug product. Formulation F1 changed to
F2 while analytical processing changed from M1 to M2. Three lots from each period
were sampled at the same lifecycle age. No unmeasured quality attribute is covered
by this packet.

**A1 — original reports.** Prechange lots, analyzed by M1, reported 1.0, 1.1, 1.0%
aggregate. Postchange lots, analyzed by M2, reported 1.6, 1.7, 1.6%. Those reports
alone confound process period with analytical processing.

**A2 — existing blinded crossover.** Representative retained aliquots from the six
lots were processed by both methods in balanced order. Sample stability and
handling were established for the comparison. All prespecified runs completed.

| Lot / period | M1 aggregate % | M2 aggregate % |
| --- | ---: | ---: |
| B1 / F1 | 1.0 | 1.6 |
| B2 / F1 | 1.1 | 1.7 |
| B3 / F1 | 1.0 | 1.6 |
| B4 / F2 | 1.0 | 1.6 |
| B5 / F2 | 1.1 | 1.7 |
| B6 / F2 | 1.0 | 1.6 |

**A3 — analytical capability report, applicable to A2.** Independent
characterization identified that M2's integration rule includes a nonaggregate
component of 0.6 percentage points in both matrices. M1 resolves that component.
Aggregate specificity, recovery, precision, and the relevant range were
demonstrated for M1 in both F1 and F2. The comparison can resolve a 0.6-point
aggregate change; it does not establish absence of smaller changes or effects on
other attributes. All of these are supplied synthetic findings.

**A4 — prospective contrast.** The crossover was designed to separate a
method-associated reporting shift from a process-period difference for this
aggregate measurement. It was not a complete product comparability study.
No criteria for overall comparability or product disposition are supplied.
